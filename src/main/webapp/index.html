🎓 Object-Oriented Programming (OOP) Architecture

Key OOP design patterns and concepts implemented in Java 17 for this project:

1. Abstraction
Transaction is an abstract base class defining core fields and abstract methods getSignedAmount() and getType(). It cannot be instantiated directly.
2. Inheritance
Income and Expense inherit all common transaction state (id, amount, date, description, category) from Transaction, avoiding code duplication.
3. Polymorphism
Income overrides getSignedAmount() to return +amount; Expense returns -amount. Account.calculateBalance() evaluates signed amounts polymorphically.
4. Encapsulation
Account and Transaction protect internal lists and fields with private access and return Collections.unmodifiableList, validating amounts against InvalidAmountException.
5. Interfaces & Strategy
StorageService (implemented by LocalStorageService) and ReportGenerator<T> (implemented by MonthlyReport, CategoryReport, IncomeVsExpenseReport) decouple implementations via contracts.
6. Exception Hierarchy
Custom domain exceptions (InvalidAmountException, TransactionNotFoundException, ValidationException) extend ExpenseTrackerException for graceful error recovery.
